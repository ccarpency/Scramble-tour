# Scramble Tour Prototype

This is the first playable MVP of the golf scramble team-building game.

## Run it
Open `index.html` in a web browser.

## Current features
- Four starting golfers with different strengths
- Team management screen
- Recruit a fifth golfer
- Rookie Open tournament
- 18-hole round
- Strategic choices for tee shot, approach, short game, and putting
- Randomized outcomes based on team attributes
- Score, prize money, and XP
- Simple progression loop

## Next development step
Convert this prototype into a true iOS/Android app, then add golfer progression, opponents, tournament tiers, a persistent save system, and polished graphics.
